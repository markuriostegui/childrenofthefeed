# Response agenda and counterstrategy

## ID

`10_counterstrategy_response_agenda`

## Target Chapters

- `10`

## Working Thesis

The response agenda is not an open menu but a three-reform doctrine: refactor Section 230, treat frontier AI weights as patrimony of humanity, and limit government capture by AI companies.

## Guiding Questions

- What is firmly documented?
- What is disputed?
- Which connections should be treated as hypotheses?

## Exclusions

- Do not turn conjectures into facts.
- Do not use excluded outlets as factual support.
- Do not lose date and source traceability.

## Key Disputes

- How to keep the response layer explicitly normative without pretending it is already settled legal consensus.
- How far public obligations should extend once AI firms receive state support, privileged access, or strategic protection.
- How to keep literacy, labor, competition, and public infrastructure framed as implementation arms rather than substitute remedies.
