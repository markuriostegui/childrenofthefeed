# Children of the Feed V3 Infographic Text Prompts

This document is the canonical prompt source for all literary-publication infographics.

Use it whenever regenerating or replacing assets under:

- `book/assets/generated/infographics/`

## Model and rendering rules

- Model: `gpt-image-2`
- Aspect ratio: `16:9`
- Output type: editorial infographic plate for HTML and PDF
- Typography rule: readable text is required
- Label rule: every intended label must be wrapped in double quotes
- Density rule: prefer `3-7` labels per plate
- Readability rule: labels must be large, high-contrast, crisp, and mobile-legible
- Layout rule: leave generous breathing room around every quoted label
- Failure-prevention rule: do not allow clipped words, warped letters, gibberish, overlapping labels, or pseudo-text
- Copy rule: no paragraph blocks inside the image
- Brand rule: black-glass panels, ember-red emphasis, dirty-gold connectors, pale-bone text, deep-black atmosphere, prestige-magazine hierarchy

## Shared negative prompt language

Avoid:

- tiny labels
- dense explanatory copy
- lorem ipsum
- fake dashboard gibberish
- clipped captions
- warped letters
- duplicated labels
- floating text without hierarchy
- flat corporate infographic style
- playful startup aesthetics
