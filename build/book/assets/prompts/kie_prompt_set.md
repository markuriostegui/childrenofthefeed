# Children of the Feed Visual Prompt Bible

This document is the canonical prompt source for the literary branch cover and narrative-scene program.

Use it before generating any new public-facing images for `book/`.

Infographic prompts are now maintained separately in:

- `book/assets/prompts/v3_infographic_text_prompts.md`

## Model and output standard

- Model: `gpt-image-2-text-to-image`
- Cover aspect ratio: `16:9`
- Interior illustration aspect ratio: `16:9`
- Infographic/editorial visual aspect ratio: `16:9`
- Quality goal: photoreal, cinematic, mobile-legible, emotionally immediate
- Core mood: prestige magazine meets investigative trailer frame

## Non-negotiable image rules

1. Covers and narrative scenes must not render readable typography inside the image.
2. Covers and narrative scenes must not attempt chapter titles, subtitles, labels, captions, logos, or interface text inside the image.
3. Reserve negative space for post-layout text.
4. Compose the frame so the top-left or upper-center third can hold external title treatment without covering the main subject.
5. Avoid clutter that turns into mush on a mobile screen.
6. One dominant subject, one secondary symbolic layer, one environmental layer.
7. Make the image feel like a strong YouTube thumbnail without becoming cheap clickbait.
8. Photoreal only. No cartoon, anime, collage, vector, or glossy corporate 3D.
9. Avoid malformed hands, broken faces, warped architecture, duplicated bodies, melted screens, and unreadable pseudo-text.
10. Brand palette should lean black, ember red, dirty gold, pale bone, charred brass, cold glass, cathedral smoke.

## Shared negative prompt language

Avoid:

- cartoon styling
- comic-book rendering
- generic sci-fi poster energy
- cheerful startup aesthetics
- flat corporate illustration
- neon vaporwave kitsch
- plastic faces
- overpacked dashboards
- tiny unreadable props
- visible gibberish text
- extra fingers
- duplicated heads or limbs

## Brand framing language

The recurring visual grammar should feel like:

- technofeudal
- wounded glamour
- digital cathedral
- altar, chain, gate, relic, cloud fortress, ritual light
- app logic as empire
- attention extraction as atmosphere
- young people as subjects inside a machine, not happy customers inside a product ad
