# Edición literaria en español

Los capítulos y `full_book.md` de esta carpeta son fuentes canónicas,
versionadas y revisadas de la edición literaria `es-419`. El comando
`export-book-print-spanish` solo exporta este material; no genera traducciones.

Estado de publicación: pendiente de autoría y revisión completa de los once
capítulos y del manuscrito integral.
