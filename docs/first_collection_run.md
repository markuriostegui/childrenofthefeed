## Current Interpretation

The repository is now past the initial collection stage. The active standard is no longer "first collection," but:

- corpus discipline,
- reform alignment,
- traceable chapter prose,
- and paper-format derivative production.

## Ongoing Quality Rule

No chapter or paper should be hardened unless the underlying vector already has:

- adequate source support under the tier hierarchy;
- source notes with prove / suggest / not-prove discipline;
- explicit evidence labels in claims;
- updated vector synthesis;
- and bounded treatment of sensitive material.
